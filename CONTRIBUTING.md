# Contribuer

Les rapports de bugs et les propositions d’amélioration sont les bienvenus.

1. Créer une branche depuis `main`.
2. Ne jamais ajouter de photos personnelles, APK, clés ou mots de passe.
3. Exécuter `./gradlew testDebugUnitTest lintDebug assembleDebug`.
4. Décrire clairement le changement et ses tests dans la pull request.

En proposant une contribution, son auteur accepte qu’elle soit distribuée sous la
licence Apache 2.0 du projet.
